# Zotero CCF 分区助手

> 在 Zotero 里自动识别**论文的 CCF 分区**与**中科院分区**，并把结果写成一行摘要。

原来的 `zotero-ccf-info` 需要手动右键、结果存在子笔记里、会议/期刊名稍有不同就识别不出来。
这个版本把这些都改掉了。

- Nature / Science / Cell 及其大子刊有独立的 **CNS 顶刊属性**，不会再显示成「无分区」。
- 新增了全库扫描进度条、设置页占位符说明、以及排查列显示问题的自检入口。

> 英文 README（含截图占位、开发与发布说明）：
> [README.md](https://github.com/ZBigFish/zotero-ccf-rank#readme)

## 1. 安装

1. 构建产物在 `build/zotero-ccf-rank.xpi`。
2. 打开 Zotero → **工具 → 插件 → 齿轮 → Install Add-on From File…**，选择该 XPI。
3. 重启后打开 **编辑 → 设置 → CCF 分区助手**。

> Zotero 9 不再加载「直接丢进 profile 的 extensions 目录」的插件，请用上面的插件对话框安装。

第一次安装后建议做的事：

0. 从 [Releases](https://github.com/ZBigFish/zotero-ccf-rank/releases/latest) 下载
   `zotero-ccf-rank.xpi` 安装的话，Zotero 之后会**自动检查更新**，不用手动换包。
1. 设置页 → **自动识别** → 点 **扫描全库并补齐**，让已有文献都拿到分区信息。
2. 设置页 → **数据来源与缓存** → 点 **预取文献库期刊**，把库里出现的期刊一次性写进本地缓存（之后基本不再联网）。
3. 在文献列表表头右键，勾选 **分区汇总** 列（默认已开启）。

## 2. 你会看到什么

### 分区汇总列

```
中科院1区 CCF-A TPAMI          ← 期刊：中科院分区 + CCF 分区 + 刊名缩写
中科院2区 CCF-B ICSE
CCF-A NeurIPS                  ← 会议：中科院分区对它不适用，{cas} 自动消失
arXiv预印本 arXiv               ← arXiv / CoRR（同样是 {cas} 自动消失）
无分区 COLM                     ← 已知但 CCF 未收录的会议
无分区                          ← 确实查不到
无中科院分区 CCF-B JFS          ← 期刊但本地还没查到分区
Nature                          ← CNS 正刊：只显示刊名，不带中科院分区
Nature子刊 NC                   ← CNS 大子刊：族名 + 缩写
Science子刊 SciRobot
Cell子刊 CellRep
```

格式完全由你在设置里控制，默认模板是 `{cas} {ccf} {top} {venue}`。

> 如果你是从旧版本升级，模板里没有 `{top}`。到设置页「可用占位符」表里
> 点一下 `{top}` 那一行即可插入；不加的话，CNS 期刊这一格只会少显示这一段。

### 条目信息面板

选中条目后，右侧「信息」里会多一行 **分区汇总**，内容和列一致。

### 条目「其他」字段（Extra）

```
CCF-RANK: A
CCF-VENUE: TPAMI
VENUE-TYPE: journal
RANK-SOURCE: dblp
RANK-UPDATED: 2026-09-12
CAS-ZONE: 1区
CAS-VENUE: IEEE TRANSACTIONS ON PATTERN ANALYSIS AND MACHINE INTELLIGENCE
```

好处：

- 数据是普通字段，能搜索（在 Zotero 搜索框输入 `CCF-RANK: A` 即可筛选）、能导出、能同步；
- 不再为每篇论文创建子笔记；
- 只改动属于本插件的这几行，其它插件写进 Extra 的内容原样保留（Citation Key 等不受影响）。

## 3. 自动识别

| 场景           | 行为                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------- |
| 新加入文献     | 后台自动识别（默认等待 4 秒，避免 Zotero 还没写完元数据）。可在设置中关闭或调整等待时间。 |
| 已有老文献     | 设置页点 **扫描全库并补齐**；已识别过的条目会跳过。                                       |
| 想强制重来     | 设置页点 **强制重新识别全库**，或右键选中条目 → **重新识别分区信息（忽略缓存）**。        |
| 只想处理选中的 | 设置页点 **识别选中条目**，或右键 → **识别分区信息**。                                    |
| 扫描中途想停   | 设置页点 **停止**。                                                                       |

全库扫描的入口在 **工具 → 扫描全库并补齐分区信息**，以及条目右键菜单的同一项。
文献列表顶部工具栏没有放按钮：那一条工具栏是所有插件共用的，多一个图标会压到别人的按钮上。

## 4. 为什么以前会「显示无分区」，现在能识别出来

会议/期刊名在不同条目里写法五花八门，插件在比较前会先做归一化：

| 归一化处理                             | 例子                                                                                         |
| -------------------------------------- | -------------------------------------------------------------------------------------------- |
| 去届次                                 | `The 41st ...` → `...`                                                                       |
| 去序数词                               | `Twenty-Eighth Annual Conference on ...` → `...`                                             |
| 去年份                                 | `(CVPR 2024)`、`2024 IEEE/CVF ...` → `...`                                                   |
| 去卷期号                               | `Vol. 12, No. 3`                                                                             |
| 去地点                                 | `..., Seattle, USA`、`held in Rome`                                                          |
| 去套话                                 | `Proceedings of the`、`International`、`Annual`、`Workshop`                                  |
| 忽略大小写、标点、连字符、`&` 与 `and` | `IEEE Trans. Pattern Anal. Mach. Intell.`                                                    |
| 忽略词序                               | `Operating Systems Principles, Symposium on`                                                 |
| 缩写 ↔ 全称                            | `TPAMI` ↔ `IEEE Transactions on Pattern Analysis and Machine Intelligence`                   |
| 首字母缩写                             | `IEEE Trans. Pattern Anal. Mach. Intell.` → `TPAMI`                                          |
| 括号里的缩写优先                       | `... Computer Vision and Pattern Recognition (CVPR)` → `CVPR`（而不是按名字首字母猜出 `PR`） |

同一主题的期刊与会议在归一化后可能撞车（如《IEEE Transactions on Multimedia》与 ACM MM 都变成 multimedia），此时按**原始名称的吻合度**再按 CCF 等级决定，且优先取与条目类型（期刊/会议）一致的那个。Journal of the ACM、Proceedings of the IEEE 这类全是套话的名字也能识别（会退回到完整词表比较）。

匹配顺序（从强到弱）：完全一致 → 明显缩写 → 首字母缩写 → 紧凑串（忽略词序/分隔符）→
包含关系（覆盖率 ≥ 70%）→ 模糊匹配（相似度 ≥ 0.8）→ 整串就是缩写。

**仍然识别不出来怎么办？** 设置页 → **自定义别名映射**，加一行：

| 匹配名称                   | 缩写  | 全称                     | CCF | 中科院分区 |
| -------------------------- | ----- | ------------------------ | --- | ---------- |
| `Journal of Fancy Studies` | `JFS` | Journal of Fancy Studies | C   | 3区        |

匹配名称也可以直接写 ISSN（如 `1234-5678`）。

## 5. 中科院分区数据

- 数据取自 **LetPub** 的公开检索页（不登录、不抓私有接口），一次请求就能拿到 ISSN、期刊名、影响因子和中科院分区。
- 结果按 ISSN / 刊名规范化后存到本地：`<Zotero 数据目录>/ccf-rank/cache/cas-journals.json`。
- **本地优先、过期再联网**：查过的期刊立刻返回；超过「有效期」（默认 30 天）才会后台重新查询，发现变化就自动刷新对应条目的记录。
- 请求间隔默认 2000 ms，请尽量不要调低——LetPub 是免费服务。
- **导入/导出**：设置页可以把缓存导出成 JSON，也可以导入 JSON / CSV / TSV 分区表（列名支持 `issn`、`journal/name/期刊`、`zone/分区/quartile`、`category/大类`）。这样即使离线也能用。

> CCF 分区来自插件内置目录（677 个会议/期刊），不依赖网络；DBLP 只用于把标题对应到具体会议/期刊。

## 6. 设置项一览

| 分组           | 内容                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------- |
| 自动识别       | 启用插件、新条目自动识别、跳过已识别、新条目等待时间(ms)、扫描/强制重扫/识别选中/停止           |
| 分区汇总格式   | 模板、分隔符、是否显示 `CCF-` 前缀、`无分区` / `arXiv预印本` / `无中科院分区` 文案              |
| 列与条目面板   | 汇总列开关与标题、CCF 列、中科院分区列、引用次数列、条目面板行                                  |
| 数据来源与缓存 | DBLP 接口、LetPub 开关、缓存有效期(天)、请求间隔(ms)、更新过期/重建全部/预取期刊/导入/导出/清空 |
| 自定义别名映射 | 上面那张表                                                                                      |
| 写入与迁移     | 迁移后是否删除旧笔记（旧版笔记始终会被读取）                                                    |

模板可用占位符（设置页里每一项都带说明和示例，点一下即可插入到模板光标处）：

```
{ccf}        CCF-A（或 无分区 / arXiv预印本 / 不适用）
{cas}        中科院1区（期刊没有分区时显示 无中科院分区；会议/预印本/图书自动省略）
{venue}      期刊/会议简称，如 TPAMI
{venueAbbr}  同 {venue}（原始值）
{ccfAbbr}    只取等级字母，如 A
{casAbbr}    只取区号，如 1区
{type}       journal / conference / preprint / other
{typeLabel}  期刊 / 会议 / 预印本 / 其它
{year}       发表年份
{updated}    最近识别日期
{citation}   引用次数（有数据时）
```

常用组合：

```
{cas} {ccf} {venue}      → 中科院1区 CCF-A TPAMI   （默认）
{ccf} {venue}            → CCF-A TPAMI
{ccf} {venue} · {cas}    → CCF-A TPAMI · 中科院1区
{typeLabel} · {venue}    → 期刊 · TPAMI
```

## 7. 从旧版升级

旧版把结果放在标题为 `CCF Info & Citations` 的子笔记里。安装本插件后：

- 读取条目时会自动兼容旧笔记（即使还没迁移，列也能显示旧数据）；
- 在设置里执行一次扫描后，结果会写进 Extra；
- 想清理旧笔记：**写入与迁移 → 迁移成功后删除旧笔记**；
- 旧版插件（Zotero CCF Info）与本插件 ID 不同，可以共存，确认无误后再卸载旧版。

## 8. 常见问题

**Q：一直显示「无分区」？**
先看设置页 **数据来源与缓存** 里的缓存条数；再在设置里点「识别选中条目」看是否联网失败。
若网络受限，可关闭 DBLP 查询——插件会完全依赖条目元数据匹配（覆盖率会下降）。

**Q：中科院分区迟迟不出来？**
中科院分区只对**期刊**有意义，会议与 arXiv 会主动跳过。首次查询需要联网，之后的同刊条目立即命中缓存。

**Q：影响因子/中科院分区是不是最新的？**
以 LetPub 当前页面为准；你可以随时在设置里「重建全部分区数据」或导入自己维护的分区表覆盖。

**Q：数据会不会被同步到别的机器？**
会。Extra 字段属于条目数据，会随 Zotero 同步；本地期刊缓存文件不会同步，但会在需要时自动重建。
